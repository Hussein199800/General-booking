# نسخة العرض على الجوال

**الرابط:** https://hussein199800.github.io/General-booking/

نسخة العرض تتيح لكم متابعة تقدّم العمل من الجوال أو الحاسوب. تُحدَّث تلقائياً بعد
دقائق من كل تعديل يُرفع إلى المستودع.

## ما الذي تحتويه؟

| الشاشة                      | ما يمكن تجربته                                                                                                                                                                             |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **الصفحة الرئيسية**         | الخدمات الإلكترونية وضمانات النظام وروابط الشاشات.                                                                                                                                         |
| **تسجيل الدخول**            | شكل شاشة دخول الموظفين (كلمة مرور ورمز تحقق ثنائي). الدخول الفعلي يُفعَّل في المرحلة الثانية.                                                                                              |
| **لوحة أمانة السر**         | قائمة الطلبات الملوّنة حسب الأولوية، والتصفية، وفتح الطلب وتنفيذ الإجراءات: الموافقة والجدولة، والإحالة، وطلب الوثائق، والرفض. جرّب الموافقة على موعد الساعة ١٠:٠٠ لترى رفض الحجز المزدوج. |
| **جدول أعمال السيد النقيب** | مواعيد اليوم المعتمدة، ومعاينة المرفقات، وزر إعادة الجدولة الطارئة.                                                                                                                        |

## تنبيهات مهمة

- **جميع البيانات تجريبية، والأسماء وهمية.** لا يُحفظ أي إجراء، ويعود كل شيء إلى حاله عند إعادة تحميل الصفحة.
- **هذه نسخة عرض فقط وليست النظام الفعلي.** النظام الفعلي يعمل على خوادم النقابة، مع قاعدة البيانات والتشفير وحماية الدخول، ولا يُنشر على GitHub.
- **الخط:** النظام يستخدم خط Calibri حيث يتوفر (أجهزة ويندوز). أما الآيفون فيعرض خط النظام العربي (SF Arabic)، وأندرويد خطه العربي الافتراضي، لأن Calibri غير مثبَّت على الهواتف ولا يحق نشره مع الموقع بموجب ترخيصه.
